# News Bot

Telegram-бот для пересылки двух типов еженедельных новостных обзоров из Gmail в Telegram.

**Схема:** ChatGPT отправляет письмо через Gmail → Google Apps Script считывает письмо из «Отправленных» → HTTPS-запрос на Bothost → Telegram-бот сохраняет обзор и рассылает его подписчикам.

## Файлы

- `bot.py` — Flask-сервер Telegram Webhook и приёмник писем `/ingest`.
- `Gmail.gs` — Google Apps Script для пересылки писем владельца Gmail.
- `requirements.txt` — зависимости Python.
- `.env.example` — пример переменных **без настоящих секретов**.

## Настройка Bothost

Подключите репозиторий к Bothost, ветка `main`, точка входа `bot.py`. Подключите публичный HTTPS-домен.

Создайте переменные окружения:

| Переменная | Значение |
|---|---|
| `BOT_TOKEN` | Токен от @BotFather |
| `WEBHOOK_SECRET` | Случайный секрет для Telegram Webhook |
| `INGEST_SECRET` | Другой случайный секрет для Google Apps Script |
| `ALLOWED_IDS` | Числовые Telegram ID получателей через запятую |
| `PUBLIC_URL` | HTTPS-домен бота без пути, например `https://bot.example.com` |

`PORT` обычно задаётся платформой автоматически.

Проверьте `https://ВАШ-ДОМЕН/health`. Получите ID подписчика из ответа бота на `/start` (при отсутствии ID в `ALLOWED_IDS` бот покажет ID). Добавьте ID в Bothost и перезапустите бота.

## Чистое меню Telegram

При нажатии кнопок бот удаляет ранее открытые **меню и обзоры, просмотренные вручную**. Еженедельные обзоры, доставленные автоматически, не удаляются.

Это поведение включается после обновления кода на Bothost. Сообщения, отправленные до обновления, могут остаться, поскольку их идентификаторы не записывались.

## Настройка Gmail

**Владелец Gmail**, из которого реально отправляются обзоры, открывает [script.google.com](https://script.google.com), заменяет весь `Код.gs` содержимым `Gmail.gs` и задаёт свойства проекта:

- `INGEST_URL` = `https://ВАШ-ДОМЕН/ingest`
- `INGEST_SECRET` = точно тот же `INGEST_SECRET`, что и в Bothost

После этого **владелец Gmail** запускает `testLatestEmail` (разовый тест) и `activateMailSync` (таймер каждые 5 минут). Нужно подтвердить разрешения Google на доступ к почте.

**Важно:** подключение редактора к чужому Apps Script не предоставляет ему прав читать Gmail владельца. Синхронизацию должен авторизовать владелец почты. Не запускайте одновременно старый `pollTelegram` / `forwardNews` и новую версию.

## Проверка

1. Отправьте боту `/start`, проверьте кнопки.
2. Проверьте `/health` по HTTPS.
3. Запустите `testLatestEmail` под Gmail владельца, убедитесь, что обзор появился в Telegram.
4. Запустите `activateMailSync`, проверьте наличие триггера `checkMail`.

## Ограничения

Скрипт сейчас отслеживает **исходящие** Gmail письма с темами «Рынок бытовой химии» и «НОВОСТИ». Он **не читает автоматически ответы из чатов ChatGPT** и не подходит для уведомлений ChatGPT во «Входящих» без изменения фильтров.

Не храните реальные токены или секреты в репозитории. Входящие HTTP-запросы защищены секретами. База SQLite хранится в `/app/data/news_bot.sqlite3`.

Развёртывание на Bothost и доставка на реальном Gmail/Telegram требуют отдельного живого теста.
